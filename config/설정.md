# PI 프로세스 캔버스 설정

> **이 파일만 고치면 툴에 반영됩니다.** 코드(.ts / .tsx)는 건드리지 않아도 됩니다.
>
> - 고친 뒤 빌드하면 `release/pi-canvas.html` 이 새로 만들어집니다.
> - 형식이 잘못되면 빌드가 멈추고 **몇 번째 줄이 문제인지** 알려줍니다.
> - 목록은 `- ` (하이픈 + 띄어쓰기)로 시작합니다. `>` 로 시작하는 줄은 설명이라 무시됩니다.

## 기본 정보

> 체계 ID: 체계를 크게 바꾸면 새 값으로 바꿉니다(예: hr-edu-2026-09). 제출 파일에 함께 저장됩니다.
> 직접 입력 허용: `예` 면 교육생이 목록에 없는 L1–L3를 직접 입력할 수 있습니다. 확정본을 넣으면 `아니오` 를 권장합니다.

- 체계 ID: hr-temp-2026-09
- 체계 이름: 인사 프로세스 체계 (임시)
- 직접 입력 허용: 예

## 프로세스 체계 (L1 › L2 › L3)

> 들여쓰기(띄어쓰기 2칸)로 레벨을 나타냅니다. 첫 단계 = L1, 한 번 들여쓰면 L2, 두 번 들여쓰면 L3.
> L1 이름 뒤 `[HR]` 처럼 대괄호로 코드를 적습니다. L2·L3 코드는 순서대로 자동으로 붙습니다(HR.01, HR.01.01 …).
> 모든 L1 에는 L2 가, 모든 L2 에는 L3 가 한 개 이상 있어야 합니다. L4 는 교육생이 직접 씁니다.

- 인사 [HR]
  - 인력계획

    - 조직 설계
    - 정원(T/O) 관리
  - 채용

  - 인사운영

    - 휴직·복직

  - 평가

  - 보상

## 작성 규칙

> L5 활동 개수가 이 범위를 벗어나면 교육생 화면에 작성 팁이 표시됩니다(저장은 막지 않음).

- 권장 활동 수 최소: 8
- 권장 활동 수 최대: 20
